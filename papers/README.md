# Papers

Manuscripts about CogLean, one directory each.

- `2026_multidigit/`: *CogLean: Towards a Cumulative, Machine-Checked Theory of Cognition*. The methodology paper, with multi-digit addition as the central demonstration. `make` builds `paper.pdf` and the accompanying talk, `talk.pdf` (slides) and `talk-notes.pdf` (with a spoken paragraph per slide). `EDITORIAL_NOTE.md` lists its novelty claims, the objections to expect, and what still needs checking. Drafted from `notes/20261031_paper_drafting_instructions.md`.

- `2026-view-application/`: *Concept Formation by View Application: A Second Domain on Shared Foundations in CogLean*. It does not introduce CogLean; it takes the library to concept and theory formation (view application, Shrager 1987, on a microwave), reusing CogLib's memory interface and laws, the confusion-error phenomenon and the decision cycle. Same build and files as above.

The earlier multi-digit paper, which predates the integrated model, is in `MultiDigit/paper/`.
