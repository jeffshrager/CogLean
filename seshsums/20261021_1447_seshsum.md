# Session summary, 2026-10-21 14:47: the missing pieces of MultiDigit

## Done (commit ce1af6c)

All the open items from the previous summary that belong to MultiDigit.

- **EPAM nets are clean** (CogLib, `Process/DiscriminationLearning`). A net is clean when each image is stored once and recognized as itself (`Net.Clean`).
  - `learn_clean`: learning keeps a net clean.
  - `learnAll_clean`: every net learned from an empty one is clean.

  So Lemma A's hypothesis holds for every net EPAM learns, and the near-miss predictions hold for learned nets with no extra hypothesis (`near_miss_200_learned`, `near_miss_20_learned`).
- **Column backup** (`MultiDigit/Columns.lean`): units, tens, hundreds, each added by a single-digit process with carries. That process can be the DOA trial itself (`doaFact`); MultiDigit now requires StrategyChoice for this.
  - `columns_place_value`: the answer is exactly r₀ + 10 r₁ + 100 r₂, so carrying adds no error.
  - `columns_exact`: correct columns give a correct answer.
  - `one_column_errs`, `column_error_is_doa_error`: if two columns are certain, the problem errs exactly when the third does. The error is the single-digit error moved to its place. For example, 2 + 3 → 4 in the tens column makes 120 + 130 = 240.
- **Learning:**
  - DOA's A6 is now stated (`SC.strengthen`). `SC.correct_strengthening_lowers_errors` says learning from a correct answer never raises retrieval errors, whichever strategy produced it. This is how backup strategies improve later retrieval. It is Theorem 12 in `THEOREMS.md`.
  - MultiDigit, `Learning.lean`:
    - `discrimination_removes_confusion`: after a confused problem is learned, it uses its own associations, the problem it was confused with is untouched, and the net stays clean.
    - `discrimination_then_columns`: a newly discriminated problem whose associations don't yet clear the criterion is worked out by the columns on every trial.
  - Together these predict a learning sequence: a confident error, then (after discrimination) slow column work, then (after strengthening) fluent, correct retrieval.
- **Example:** the column algorithm with carries, 234 + 578 = 812.
